# Seethal's JavaScript Practice

Beginner JavaScript programs:

- `01_Basics.js` prints a greeting and a number.
- `02_Basic.js` prints a greeting and a number.
- `03_Sum.js` adds two numbers.
- `04_OddEven.js` checks whether a number is odd or even.

To run a program with Node.js, open a terminal in this folder and enter, for example:

```bash
node 01_Basics.js
```
