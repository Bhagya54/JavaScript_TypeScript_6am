# VS Code Keyboard Shortcuts (Windows & Mac)

> Mac keys: `Cmd` = ⌘, `Option` = ⌥, `Ctrl` = ⌃, `Shift` = ⇧
> A shortcut like `Ctrl+K Ctrl+S` means press `Ctrl+K`, release, then press `Ctrl+S`.

## General

| Action | Windows | Mac |
|---|---|---|
| Command Palette | `Ctrl+Shift+P` / `F1` | `Cmd+Shift+P` / `F1` |
| Quick Open file | `Ctrl+P` | `Cmd+P` |
| Settings | `Ctrl+,` | `Cmd+,` |
| Keyboard Shortcuts list | `Ctrl+K Ctrl+S` | `Cmd+K Cmd+S` |
| New window | `Ctrl+Shift+N` | `Cmd+Shift+N` |
| Toggle sidebar | `Ctrl+B` | `Cmd+B` |
| Zen mode | `Ctrl+K Z` | `Cmd+K Z` |
| Zoom in / out | `Ctrl+=` / `Ctrl+-` | `Cmd+=` / `Cmd+-` |

| Action | Windows | Mac |
|---|---|---|

| Insert line below | `Ctrl+Enter` | `Cmd+Enter` |
| Insert line above | `Ctrl+Shift+Enter` | `Cmd+Shift+Enter` |
| Indent / Outdent line | `Ctrl+]` / `Ctrl+[` | `Cmd+]` / `Cmd+[` |
| Undo | `Ctrl+Z` | `Cmd+Z` |
| Redo | `Ctrl+Y` | `Cmd+Shift+Z` |
| Format document | `Shift+Alt+F` | `Shift+Option+F` |
| Toggle word wrap | `Alt+Z` | `Option+Z` |
| Fold / Unfold region | `Ctrl+Shift+[` / `Ctrl+Shift+]` | `Cmd+Option+[` / `Cmd+Option+]` |
