2. Reserved only in strict mode

  • let: declare a block-scoped variable
  • static: static class member
  • yield: pause a generator function
  • implements, interface, package, private, protected, public: reserved for future use

3. Context-dependent keywords

These act as keywords only in certain places, so they can still be used as names elsewhere.

  • await: wait for a Promise (reserved inside modules and async functions)
  • async: declare an async function
  • of: used in for...of loops
  • get / set: define property getters and setters
  • as / from: used in import and export statements
  • arguments / eval: can't be assigned to in strict mode

4. Future reserved word (always)

  • enum

5. Old reserved words (ES1–ES3, no longer reserved)

Avoid these anyway to keep code compatible with old engines.

abstract boolean byte char double final float goto int long native short synchronized throws transient volatile

6. Special values (globals, not keywords)

  • undefined, NaN, Infinity: global properties. They aren't keywords, but don't redefine them.
