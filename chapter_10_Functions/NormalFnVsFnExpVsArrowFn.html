3 Ways to Make a Function

Same job: a little box that does work when you call it. 📦

🏠

Normal (Declaration)

function add(a, b) {
  return a + b;
}
🎁

Function Expression

const add = function (a, b) {
  return a + b;
};
🏹

Arrow Function

const add = (a, b) => a + b;
